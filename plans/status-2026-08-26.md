### 3. The agent loop became a governed control loop (M11)

`AgentLoopManager` decorates Spring AI's `ToolCallingManager` **without patching the Spring AI loop**. A per-turn `AgentTurn` enforces a **soft round cap (16 — further calls get a synthetic "wrap up")**, a **hard cap (18 — `returnDirect` forces the loop shut)**, an identical-call repeat guard, and a per-turn interactive-tool budget. An `AgentRoundInterceptor` chain (loop guard → HITL approval → file upload → image reference) can claim any tool call before it executes; guard outcomes are counted on a `chat.tool.loop` meter. Classes: `service/agent/{AgentLoopManager,AgentTurn,AgentRoundInterceptor,HitlApprovalInterceptor,FileUploadInterceptor,AgentLoopHarness}`.

### 4. Safety became the product thesis — HITL, risk tiers, and a tool-hash ledger

- **Human-in-the-loop tool approval** on two gates (chat dialog + MCP elicitation for external clients), with **friction that scales by risk level**: L4 renders approve in the error theme, **L5 keeps approval disabled behind an "I reviewed the arguments and accept the risk" checkbox**.
- **Dual-level risk chips** — inherent risk shown alongside the HITL-mitigated effective level, so mitigation is visible rather than silently overwriting the raw score.
- **`McpToolHashLedger` + `CanonicalHasher` + `DefaultIntegrityVerifier` + `McpToolPoisoningScanner`** — a rug-pull ledger over upstream tool schemas, with integrity re-review recorded as an approval. `ee69628` made the fingerprint **key-order independent** to kill false rug-pull flags. A ~30-class `service/mcp/risk/` package now exists (composition shadowing rules, auth/host classifiers, publish-risk calculator, risk-event MDC keys and sinks).
- **OWASP MCP Top 10 coverage mapping** published and linked from the architecture nav (`067a995`).
- **L5 destructive filesystem tier** — `searchInFiles`, `editTextFile`, `appendTextFile`, `copyFile`, `moveFile`, `deleteFile`, `deleteDir` (filesystem family 11 → 18 tools), workspace-scoped and per-conversation isolated.
- **Actuator hardening** — `beans` dropped from the shipped default exposure (now `health,info,metrics,prometheus`), pinned by a test.
- CI gained a **default-tool integrity manifest verification job** on every push (`2d58121`).

### 5. Desktop app: Electron launcher matured into a shipping product

Tray/menubar residency (close hides rather than stops the server), **Recent Activity** menu that reopens on the last conversation via `?conv=` URL + title sync, **auto-update** with stage-aware M < RC < GA ranking (`electron-updater` NSIS/deb/rpm on Windows/Linux; semi-automatic on unsigned macOS), **Ollama auto-start** with a 15-second readiness poll, **on-device Whisper voice input** (four commits of packaging work to get the whisper native addon rpath/asar/darwin-arch right), Apple-Silicon **MLX auto-select** with an `mlx` Spring profile, secrets `chmod 600` + credential-gated launch, macOS keychain probe skipped on first run. Code signing arrived at the end of the window: `CODE_SIGNING_POLICY.md` + SignPath attribution (2026-07-23, 2026-08-19).

### 6. Multimodal and tooling surface expansion

Native **image attachments** (up to five per message; browser-side resize + EXIF; content-addressed storage; capability check that warns when the selected model cannot actually see, including the Apple-Silicon `-mlx` false-positive), a `describeImage` tool that re-summons an earlier image, a **fourteen-tool visualization family** (ECharts charts, diffs, multi-point Leaflet maps) rendered as review-then-act **action cards**, a `requestFileUpload` tool (spreadsheets → CSV via SheetJS inside the conversation workspace), a **prompt library with variable templates**, per-chat memory window, and presets (**Self-equipping agent** as the new chat default, Workspace organizer, Image analyst, Document detective). Bundled tool catalog reached **115 tools**. Default Ollama chat model moved `qwen3.5:2b` → **`qwen3.5:4b`** (smallest build shipping vision tensors).

### 7. Observability plane: 14 dashboards backed by a persisted ring buffer

Overview, Tokens & Cost, AI Models, Tool Studio, MCP Servers, MCP Inspector, Vector Database, Agentic Chat, **Safety** (risk-event timeline), Host, **Ollama**, Web Application, Logs, Traces — every number computed from the running services, backed by a **bounded ring buffer with dated disk persistence**, drill-through from row → trace timeline → raw spans → back into the conversation. Package `observability/` now carries its own ring buffers, bucketed/windowed time series, pricing service, and system/Ollama metric collectors. Home was reworked into a **launchpad** with a live System & Observability panel.

### 8. Anonymous telemetry, opt-out, with a privacy walk-back

Production-gated content-free usage events (13 kinds), extended in M12 with daily `mcp_server_active` and `model_usage` aggregates; development runs never send; one switch (`SPRING_AI_PLAYGROUND_TELEMETRY_ENABLED=false`) covers web app, launcher windows, and spawned backend. A follow-up fix removed conversation id and title from `page_view` payloads after they were found to be leaking through browser-supplied page location/title.

### 9. Test suite freed from Docker, Ollama, and a local MCP venv (M12)

`f1e7a83` + `a065c83` replaced external-dependency integration tests with **loopback MCP coverage (streamable HTTP + SSE), an in-process stdio test server, and browserless render tests** across chat/home/MCP/observability/tool-studio/vector-store views — asserting rendered content and flows (per-entry dashboard identity, model-download failure paths, the exact `page_view` payload) rather than bare component mounting. `067472c` then **dropped `skip-tests` so CI runs the full suite on every push**, scoped workflow permissions to `contents: read`, and fixed the concurrency group key. **This invalidates the standing note in the local `CLAUDE.md` that "tests are skipped in CI because they require Ollama."** Test classes: 116 → 179.

### 10. Breaking config change: custom env aliases removed (M12)

`6fb741f` deleted sixteen ad-hoc env names (`OBS_RING_CAPACITY`, `OBS_RETAIN_DAYS`, `TOOL_STUDIO_FS_BASE`, `SPRING_AI_PLAYGROUND_MCP_*`, `SPRING_AI_PLAYGROUND_ACTUATOR_INCLUDE`, the six `SPRING_AI_*_OBSERVE_*` toggles, …) in favour of **Spring Boot relaxed binding only**, with a guard test that fails the build if a new alias reaches the shipped yaml. `SERVER_PORT` and `OPENAI_API_KEY` survive as ecosystem-standard names.

### 11. Documentation became a first-class deliverable

Docs tree 157 → **280** files with an mkdocs site (`spring-ai-community.github.io/spring-ai-playground`), a `docs-site.yml` workflow, Google Search Console verification, a **doc-count guard**, an integration diagram + external-connections page, agentic-chat / prompt-library / context-engineering guides, HITL pages with per-level dialog captures, OWASP mapping, repeated screenshot recaptures, and a YouTube demo series (ep. 6 poster + 30-second trailer). Governance docs landed too: `CODE_OF_CONDUCT.md`, `CODE_SIGNING_POLICY.md`.
